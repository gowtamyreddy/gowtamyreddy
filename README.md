# Gowtamy Reddy
Founding AI/ML Engineer | Building LLM applications, RAG systems and agent workflows

I build AI systems that have to work on real documents, for real people, where a wrong answer has a cost. My focus is the part most demos skip: evaluation. Every project below ships with a live demo or published evaluation numbers, so you never have to take my word for anything. You can run it.

## Flagship projects
- **EvidenceRAG** — Document Q&A that answers only from retrieved citations, with a guaranteed refusal when the evidence is not there. Live demo: https://Gowtamy-evidencerag.hf.space
- **Forkwise** — Agent observability you run locally: fork and replay any agent run from step N, diff the outcomes, track cost per successful task. Live demo: https://Gowtamy-forkwise.hf.space
- **TrustLens** — An eval gate for retrieval changes: compares two versions of a RAG system on a golden set and gives a ship or do-not-ship verdict.
- **CitedAgent** — Research agent that plans sub-questions, retrieves from real papers, verifies every claim against a citation, and refuses what it cannot support.
